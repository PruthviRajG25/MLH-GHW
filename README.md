# Aster Personal Portfolio

A simple, modern, and responsive personal portfolio built for the GitHub Copilot Quickstart challenge. It uses plain HTML, CSS, and JavaScript, so it has no build step or paid dependencies.

## Features

- Home, About, Skills, Projects, and Contact sections
- Responsive navigation and layout for desktop, tablet, and mobile
- Three sample projects with technology labels
- Contact form with browser validation and JavaScript feedback
- Smooth scrolling, hover effects, and CSS-generated artwork

## Technologies

HTML, CSS, JavaScript, Python, and GitHub.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server:

```bash
npx serve .
```

You can also double-click `index.html` to open it directly in a browser.

## Upload to GitHub

1. Create a new repository on GitHub.
2. Open a terminal in this folder and run:

```bash
git init
git add .
git commit -m "Create personal portfolio"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace the placeholder project details, social links, and personal information in `index.html` before sharing the site publicly.
